# 5. HERO MAIN PHOTO PRODUCTION RECORD

正式採用済みHero写真の判断基準として、制作時のルールを記録する。

## Heroの役割

「運転講習」を説明する写真ではなく、**子どもとの日常に車が自然にある未来**を見せる。

Heroの心理：**これから運転を再開する一歩手前**

## 主な人物

- 30〜40代くらいの日本人女性
- 子育て中の利用者モデル
- ブランド全体で同じ利用者モデルを継続使用できるようにする
- 広告的に作り込まれすぎない自然な人物
- 派手なファッションにしない

## 子ども

- 未就学〜小学校低学年程度
- 主役にしすぎない
- 親子の日常が伝わる程度

## 車

- 一般的な日本のファミリーカーまたはコンパクトカー
- 高級車・スポーツカーにしない
- 車そのものを主役にしない

## 場所・シーン

- 日本の郊外住宅地
- 自宅前や住宅街
- 保育園・送迎などの日常を連想できる環境
- 親が子どもの荷物を車へ載せたり、これから運転席へ向かって出発する直前の自然な場面を第一候補とした

## 表情・光・色

- 満面の広告笑顔にしない
- 少し前向きで落ち着いた自然な表情
- 「運転が完全に得意」ではなく「これから一歩踏み出す」空気を残す
- 午前〜昼の柔らかな自然光
- 明るいが白飛びしすぎない
- 強い逆光・ドラマチックな光は避ける
- 低〜中彩度
- Blue Gray / Ivoryのサイトカラーと合わせやすい
- 黄色・オレンジに寄せすぎない
- 強い青や黒で自動車広告風にしない

## 写真の質感

- Lifestyle Editorial
- 自然
- 静か
- 清潔
- やさしい
- 落ち着き
- 過度なCG感・AI感を避ける
- 肌を不自然に滑らかにしすぎない
- 完璧に整いすぎた住宅広告のようにしない

## 構図

- PC / SP両方でトリミングしやすい構図
- 人物の顔・手・子ども・車が端に寄りすぎない
- テキストをHTMLで重ねられる余白を確保
- 写真内には文字を入れない
- ロゴを入れない
- CTAを画像化しない
- 価格を画像内に入れない

## NG

- 写真内テキスト
- ロゴ
- 価格
- CTA
- 教習所の看板
- 道路標識を過度に強調
- ハンドルの極端なアップ
- 高級車広告風
- スピード感
- 派手な笑顔
- 不安そうに頭を抱える表現
- 事故を連想させる表現
- 子どもを危険な位置に配置
- 左右ハンドルや道路環境が日本らしくない表現
- 車両・人体の破綻
- 指や手の不自然さ
- 過度な被写界深度
- AI特有の不自然なツヤ

# 7. ASSET RULES

- 正式素材は原則、1種類制作 → 確認 → 修正 → 正式採用 → 次の素材の順で進める
- 承認済みの元画像をプロジェクトへコピーし、元データは移動・削除しない
- 整理時は元の画像形式を維持する
- IconとLogoの透過情報を維持する
- 同じ正式素材と思われる候補が複数ある場合は、勝手に選ばず確認する
- 公開前の画像最適化までは圧縮・WebP変換を行わない
- OGP / faviconは未制作

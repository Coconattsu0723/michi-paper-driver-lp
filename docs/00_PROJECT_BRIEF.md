## サービスの基本価値

単に運転技術を教えるのではなく、**子育て中の日常を、自分で動かせるようにするサービス**として設計する。

実際の生活で使う道を、自分のペースで練習できることを重視する。

- 保育園・幼稚園・学校までの送迎ルート

- 病院までの道
- 自宅周辺の狭い道
- 自宅や施設の駐車
- 日常でよく使う交差点や道路

# 2. TARGET

## メインターゲット

**子どもの送迎をきっかけに、久しぶりに運転を再開したい子育て中の人**

## 想定像

- 30〜40代中心
- 子育て中
- 免許は持っている
- 取得後ほとんど運転していない、または数年以上ブランクがある
- 保育園・幼稚園・習い事・病院・買い物などで車が必要になった
- 家族に運転を頼り続けるのが難しくなってきた
- 「運転できたら便利」と分かっているが、怖さが強く再開できていない

## 表面的な悩み

- 何年も運転していないので怖い
- 駐車が苦手
- 狭い道ですれ違うのが怖い
- 車線変更が怖い
- 子どもを乗せて運転するのが怖い
- 自宅周辺を一人で走れる自信がない
- 雨の日や急な通院のときに困る
- 送迎を家族に頼るのが大変

## 本音

- 必要なときに、自分で子どもを連れていけるようになりたい
- 家族の予定を確認せず、自分で送迎したい
- 急な病院でも自分で動けるようになりたい
- 雨の日に子どもと荷物を抱えて移動したくない
- 「運転できないから」という理由で行動を諦めたくない
- 子どもを乗せても大丈夫だと自分で思えるようになりたい

## 行動できない理由

1. 事故や失敗への恐怖が強い
2. 何から練習すればいいか分からない
3. 家族に教えてもらうと焦ったり、うまくいかない
4. 免許を持っているのに講習を受けることへの抵抗がある

## サービス利用前の不安

- 厳しい先生だったらどうしよう
- 初心者レベルでも大丈夫か
- 長いブランクがあっても大丈夫か
- 自分の車で練習できるか
- 子どもの送迎ルートを練習できるか
- 駐車だけ練習できるか
- 補助ブレーキはあるか
- 事故時の対応はどうなるか
- 何回くらい受ければよいか
- 追加料金はないか
- 子どもを乗せて練習できるか

## 受講後に得たい変化

Before：

- 雨の日の送迎で困る
- 急な病院でも家族を待つ
- 駐車が怖くて車では行けない

After：

- 雨だから今日は車で行こうと思える
- 急な通院でも自分で連れていける
- いつものスーパーなら一人で行ける
- 必要なときに自分で動ける

## 課題から提供価値への接続

**運転することが怖くて、必要なときも誰かに頼っていた人が、自分のペースで練習し、子どもとの日常を自分で運転できるようになる。**

## 車両

### 自家用車

利用可能。

メリット：実際に日常で使う車に慣れられる。

### 講習車

利用可能。

自家用車を持っていない人、いきなり自家用車で練習するのが怖い人向け。講習車には助手席補助ブレーキを装備する設定。

## Safety設定

- 講習車は助手席補助ブレーキ装備
- 自家用車は簡易補助ブレーキ装着可能
- 講習前ヒアリング
- 車両・操作確認から開始
- 状況により公道へ出ず基礎確認から開始可能
- 交通量の少ない道から開始可能
- Instructorが安全上難しいと判断した内容は実施しない
- 希望に合わせるが、無理はさせない

「必ず希望ルートを走れる」とは言わない。

## 子ども同乗ルール

**初回講習では原則、子どもの同乗なし。**

Instructorが安全上問題ないと判断した場合、**2回目以降は子ども同乗での送迎練習も可能。**

最初から同乗OKにせず、段階を踏むことで安全性と信頼感を出す。

小雨は原則実施可能。道路・気象状況を見て判断する。

## 遅刻

**利用者が遅刻した場合、原則としてレッスン終了時刻は延長しない。**

安全確認に十分な時間を確保できない場合は、レッスン内容を変更する可能性がある。

# 6. LESSON

## 初回講習の流れ

1. 事前ヒアリング
2. 自宅または指定場所で待ち合わせ
3. シート・ミラー・基本操作確認
4. 現在の運転レベル確認
5. 本人のペースに合わせた実走
6. できたこと・次に練習することを振り返り

## 対応する練習内容

- 久しぶりの運転
- 自宅周辺
- 子どもの送迎ルート
- 駐車
- 狭い道
- 右左折
- 車線変更
- 幹線道路
- スーパー・病院など目的地まで
- 自家用車への慣れ

高速道路は、基本操作に慣れた人向けの追加レッスンという位置づけ。
